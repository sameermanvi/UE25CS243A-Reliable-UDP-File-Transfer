# UE25CS243A Reliable UDP File Transfer

This repository contains the structure for a Computer Networks project on
reliable file transfer over UDP.

Planned work:

- Implement the UDP client and server.
- Define packet formats, acknowledgements, checksums, timeouts, and retransmissions.
- Add a Mininet topology and Ryu controller for path experiments.
- Add scripts for testing transfers and collecting performance results.
- Document the design and experimental findings.
